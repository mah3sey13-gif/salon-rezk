# صالون رزق | احجز دورك يا صاحبي 💈✂️

تطبيق ويب متكامل لحجز وإدارة طوابير صالون الحلاقة **صالون رزق**، نسخة طبق الأصل ومطابقة لتصميم وميزات المنصة مع تغيير الهوية بالكامل إلى "صالون رزق".

---

## 🌟 الميزات الرئيسية

1. **الصفحة الرئيسية (`/`):**
   - عرض أيام الأسبوع المتاحة (15 يوماً قادمة بتوقيت القاهرة).
   - عرض سعة كل يوم (`X من 12 حجز`) وحالة اليوم (متاح / حجوزات قليلة متبقية / مكتمل / مغلق).
   - شريط التنبيهات الطارئة من رزق في أعلى الصفحة.
   - زر متابعة الحجز للزبائن.
   - بطاقة تواصل سريعة للاتصال برزق (`01211292518`).

2. **حجز الدور (`/book/[date]`):**
   - حجز سريع بخطوة واحدة بالاسم ورقم الموبايل المصري (11 رقماً).
   - إصدار تذكرة فورية برقم الدور `#queue_position` وبطاقة رقم الحجز.
   - حفظ الحجز تلقائياً برقم الموبايل بدون تعقيد أو تسجيل حساب.

3. **متابعة الحجز (`/track`):**
   - كتابة رقم الموبايل للبحث الفوري عن كافة الحجوزات المسجلة.
   - عرض حالة الحجز النشطة (حجزك نشط / تم الحلاقة / ملغي / تم تعديل الميعاد).
   - تنبيهات فورية في حال إغلاق اليوم للطوارئ أو تغيير الموعد.

4. **لوحة تحكم الصالون (`/admin`):**
   - تسجيل دخول محمي برمز PIN (الافتراضي: `1991`).
   - شريط تنقل أفقي بين الأيام مع مؤشر الحجوزات النشطة.
   - التحكم في ترتيب الطابور (تقديم وتأخير الزبائن بالأسهم).
   - تعليم الحجز كمكتمل بنقرة واحدة ("تم").
   - تعديل بيانات الزبون أو ملاحظات الحلاق.
   - نقل الحجز إلى يوم آخر تلقائياً مع إعادة ترقيم الأدوار.
   - إغلاق اليوم للطوارئ مع كتابة السبب أو إعادة فتحه.
   - تصفير حجوزات اليوم بالكامل.
   - نشر وإدارة التنبيهات الطارئة للزبائن.
   - تغيير رمز الدخول (PIN).

## 🚀 التشغيل المباشر

### 1. التجربة الفورية في المتصفح (بدون تثبيت أي شيء):
يمكنك فتح ملف `preview.html` مباشرة بالنقر المزدوج عليه في أي متصفح (Chrome, Edge)، وستعمل كافة الوظائف وتخزين الحجوزات والتحكم كأدمن فوراً عبر `localStorage`.

### 2. تشغيل مشروع Next.js الكامل:
```bash
# الانتقال لمجلد المشروع
cd salon-rezk

# تثبيت الحزم
npm install

# تشغيل السيرفر المحلي
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

- رمز الدخول السري (PIN): `1991`

## ☁️ النشر على Vercel
المشروع مبني بـ **Next.js (App Router)** ومتوافق بنسبة 100% مع منصة Vercel:
1. ارفع المشروع على حسابك في GitHub.
2. ادخل على [Vercel](https://vercel.com) واعمل Import للمستودع.
3. اضغط **Deploy** وستحصل على الرابط المباشر فوراً!
